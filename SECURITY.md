# Security Policy

Hackathon project (Team Ctrl200). Please report vulnerabilities via GitHub issues on this repository, or privately to the team during the event.

Key properties: server-side API key only, gitignored `.env`, upload validation + in-memory processing, allow-listed function calling with no dynamic dispatch, redacted structured logs, rounded coordinates. Details: `docs/SECURITY.md`, `docs/THREAT_MODEL.md`.
