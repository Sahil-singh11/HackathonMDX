## Sources & licensing
- iNaturalist / GBIF media: only CC0 / CC-BY / CC-BY-NC records, attribution recorded per file; NC media used for evaluation only, not redistributed if licence forbids.
- Team photos: consent + written permission recorded in the manifest.
- Synthetic quality-test images (blur/dark/overexposed/invalid) generated by `data/scripts` — safe to redistribute.
- Raw downloads live in `data/raw/` (gitignored); manifests + licences are committed.

## Artefacts
- `data/manifests/species_images.csv` — full field set per brief (path, ids, names, platform, observation id, URLs, creator, licence, licence URL, locality, date, SHA-256, split, redistribution permission, notes).
- `data/manifests/species_sources.csv` — per-source register.
- `data/rules/species_rules.json` — versioned, source-attributed deterministic rules.
- `data/rules/source_register.json` — rule sources with URL/title/dates/verification status.
- `data/processed/species_catalogue.json` — app catalogue (names, characteristics, candidate keywords).
- `docs/DATASET_CARD.md` — dataset card.

## Splits & leakage
Split by observation/photographer; augmented variants inherit the parent's split; pytest leakage test enforces no SHA or observation id crosses splits.

## Volume targets
P0: 10–15 eval images + 2–3 hero images per species + invalid/blur/lighting variants. P1: up to ten species. Downloads are streamed (no full in-memory batches), ≤4 OpenCV workers.
